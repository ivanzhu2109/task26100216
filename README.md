# task26100216

NimbusSync 离线目录移动合并库（Go 实现，纯内存、单线程调用）。

## 语义

- 目录集合固定为 `0..N`，`0` 是根目录，永远不能被移动；所有目录初始直属根。
- `Apply(folder, parent, priority)` 接收一条移动事件，事件可乱序、可重复到达；
  每个目录只保留 priority 最大的事件作为候选移动（无事件时候选父目录为根）。
- 展示关系 = 候选关系中每个有向环恰好切断 priority 最小的边（临时指向根），
  其余边（包括仅指向环、自身不在环上的边）保持不变；自指是长度为 1 的环。
- 被临时压制的移动仍是候选，环被后续事件拆散时自动恢复生效。

## API

```go
s := nimbussync.New(n)
s.Apply(folder, parent, priority)
p := s.Parent(folder)
snap := s.Snapshot() // 全部目录当前展示的父关系
```

## 验证

```sh
go test ./...
```

包含固定场景测试（环切断/恢复/旧事件与重复事件不倒退/入环低优先级边不误切/
自指/根不可移动）与随机测试（每次 Apply 后与独立慢速参考实现核对全部 Parent，
并对同一事件集合做多种乱序与重复投递核对最终 Snapshot 一致）。
